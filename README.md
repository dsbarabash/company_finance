
### «Система учета и анализа финансов Разработать базу данных для учета доходов и расходов компании. Реализовать функции для создания финансовых отчетов, анализа прибыли и расходов»


Требования
Функционал для разработчиков
MVP платформы обязательно включает в себя:

    - ER-диаграмма, представляющая структуру базы данных, включающая минимум 10 таблиц с четко определенными связями между ними.
    - Хранимые процедуры и функции для автоматизации задач и улучшения производительности, всего не менее 5 хранимых процедур и 3 пользовательских функций.
    - Оптимизация запросов и структуры базы данных с использованием минимум 5 индексов, 1 CTE (общего табличного выражения) и 1 подзапроса.
    - Мониторинг производительности базы данных.
    - Представления (Views): создание минимум 3 представлений для упрощения сложных запросов и их использования в отчетах.
    - Триггеры: разработка не менее 2 триггеров для автоматического выполнения определенных действий при изменении данных в таблицах.
    - Настройка безопасности данных с использованием не менее 1 механизма управления доступом (например, использование ролей и привилегий).
